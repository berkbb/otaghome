# User-rejected ideas

Do not propose or build these again.

| Idea | Decision |
|---|---|
| OtagHome screensaver (pictures, clock, weather) | Not wanted; the system screensaver stays |
| More UI languages than English, Turkish, Romanian | Keep the three |
| In-app language picker | The UI follows the TV's language |
| Google profile picture / Google sign-in in the top bar | Removed; accounts are in TV settings |
| Search box in the top bar | Replaced by a voice-search button |
| Large preview ("hero") area above the Favorites grid | Removed |
| Favorites as an Apple TV style carousel | Replaced by a centred grid |
| Monospace app names | Replaced by the system typeface, bold |
| Hint line always shown at the bottom | Messages appear only when something happens |
| Weather condition text ("Partly cloudy") | Icon only, so it reads in every TV language |
